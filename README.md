# Vinky's Home (vinkybb-page)

Welcome to **My Home**! 🏠 
This is the personal homepage and vintage aesthetic portfolio of Vinky.

## 🌟 About

A modern, vintage-styled personal portfolio built to showcase Vinky's work, thoughts, and aesthetic. 

## 🚀 Tech Stack

- **Frontend:** React 19 + TypeScript
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Backend/AI:** Express.js + Google GenAI

## 📦 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Install the dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables:
   - Copy `.env.example` to `.env`
   - Fill in any required keys (e.g., Google Gemini API key if needed).

### Running the Project

Start the local development server:
```bash
npm run dev
```
The application will be available at `http://localhost:3000`.

## 📜 Available Scripts

- `npm run dev`: Starts the development server.
- `npm run build`: Builds the app for production.
- `npm run preview`: Locally previews the production build.
- `npm run lint`: Runs TypeScript type checking.
